# Single boot

1. Download Ubuntu Desktop from [https://ubuntu.com/download/desktop](https://ubuntu.com/download/desktop) and create media using Ubuntu instructions.
2. Back up important files. Boot the USB and choose **Try Ubuntu** to check hardware.
3. Choose whole-disk install only if you intend to erase that disk; confirm its identity and stop if unsure.
4. After Ubuntu installs, run `bash install.sh` in this project folder.
