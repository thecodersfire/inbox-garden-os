# Dual boot

1. Back up important files and keep recovery media for your current system.
2. Download Ubuntu Desktop from [https://ubuntu.com/download/desktop](https://ubuntu.com/download/desktop). Create install media using Ubuntu instructions.
3. Boot the USB and check hardware with **Try Ubuntu**.
4. Choose **Install alongside** only if the installer clearly identifies the intended system and disk. Stop if it proposes erasing a disk or the choice is unclear.
5. Confirm both systems boot, then run `bash install.sh`. Partition changes can cause data loss; do not guess at manual layouts.
