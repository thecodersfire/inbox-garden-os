# VMware Workstation

1. Download Ubuntu Desktop from [https://ubuntu.com/download/desktop](https://ubuntu.com/download/desktop).
2. Create a new VMware virtual machine and select the Ubuntu ISO.
3. Assign resources suitable for your host; 4 CPU cores, 8 GB RAM, and 60 GB virtual disk are starting points when available.
4. Use only the VM virtual disk. Do not attach physical disks or enable raw-disk mapping.
5. Test with **Try Ubuntu**, install to the VM disk, then run `bash install.sh`.
