# Inbox Garden OS

Inbox Garden OS is an Ubuntu-based desktop setup built for email and document handling. It includes a Software app catalog, purpose-selected applications, Firefox, Opera GX, and original geometric wallpaper.

**Get Ubuntu Desktop:** [https://ubuntu.com/download/desktop](https://ubuntu.com/download/desktop)

## Set up the apps

This source repository has scripts and artwork, not an ISO or Ubuntu binaries. Install Ubuntu from the official link above, then run `bash install.sh` in this folder. It installs GNOME Software with Flathub and the apps listed in `apps.txt`.

To build a customized ISO, use Cubic on an Ubuntu host and follow [Cubic instructions](https://github.com/PJ-Singh-001/Cubic/wiki/Install-Cubic). Review license and trademark terms before distributing an image.

The `inbox-garden.svg` wallpaper is original. Inbox Garden OS is an independent Ubuntu customization, not an official Ubuntu, Canonical, Mozilla, or Opera product.
